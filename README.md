# Small Business Landing Page

A simple, responsive Next.js landing page built for testing — a fictional
local cafe and bakery called GreenLeaf Cafe.

## Sections

- Hero with a clear call to action
- Services: fresh coffee, bakery, and catering
- Menu highlights with prices
- Customer testimonials
- Opening hours and contact section

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy

This project is deployed on Vercel from GitHub.
